# Architecture Portfolio Collection

Seven original fictional architecture projects, with five unique images per project (35 images total).

Each named project folder contains five full-size 1536 × 1024 JPG images and a webp subfolder containing the same five views in a lighter format. Both formats retain the native resolution; nothing has been upscaled. The image beginning with 01 is the recommended project cover.

## Projects

- Banyan Court Residence — Courtyard residence
- Strata Terrace Apartments — Boutique apartment building
- Tide House — Coastal villa
- Stillwater Sanctuary — Meditation and wellness pavilion
- Monsoon Civic Hall — Municipal administration and public services
- Canopy Ridge Retreat — Forest hospitality retreat
- Atelier Courtyard Offices — Creative studio and office building

## Website use

Use the WebP copies for normal website galleries and the JPG copies when broad editing compatibility is useful. projects.json provides ordered image paths, dimensions, alt text, categories, and project covers. All paths are relative to this collection folder. GENERATION-PROMPTS.md contains the exact prompt set for future revisions.

## Presentation

These are AI-generated visualizations of fictional architectural concepts created for a demonstration portfolio. They are not photographs of built projects or evidence of real client commissions. A suitable website label is “Concept project · AI visualization”. Views were guided by a common exterior reference for each project; they are not derived from one CAD/BIM model, and construction accuracy or exact cross-view geometry is not guaranteed.

The reference website informed the project-gallery format. No photographs from that website are included.
