# Oculus House

Flagship concept project 08 — experimental courtyard residence.

A low circular home wraps an open tree courtyard. The planted concrete roof, curved glazing, limestone gallery and rain chain create the central architectural identity. These are design intentions, not measured environmental-performance claims.

## Files

The project folder contains five full-size JPGs. webp contains lighter copies for website galleries; originals contains the five unchanged generated PNGs. All images are at their native 1536 × 1024 resolution. Nothing is upscaled. Image 01 is the recommended project cover; image 05 is an evening alternative.

project.json provides ordered image paths, alt text, dimensions, a description and covers. GENERATION-PROMPTS.md includes the exact prompt set used with built-in image generation.

## Presentation

Original AI-generated fictional architectural concept, created for a demonstration portfolio. A suitable website label is “Concept project · AI visualization”. These are not photographs of a real built commission, and the views were guided by a common reference rather than one CAD/BIM model. Exact cross-view geometry, construction accuracy and environmental performance are not verified.
