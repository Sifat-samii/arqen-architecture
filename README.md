# ARQEN Studio

ARQEN — Architecture Studio  
Beyond Form. Beyond Space.

The complete website project is in `inle-portfolio/`.

Run `npm.cmd run dev` from this folder and visit http://localhost:3000. No dependency installation is needed. See `inle-portfolio/README.md` for customization instructions. Contact details are intentionally blank.

The website also includes Expertise (`services.html`), Studio (`studio.html`), Process & FAQs (`process.html`), Start a Project (`contact.html`), and Privacy (`privacy.html`). These pages use realistic sample studio content in `inle-portfolio/content/studio.json`, with interactive 3D studies and a local inquiry preview. The original real-contact fields remain blank; the sample email and telephone do not receive inquiries.
